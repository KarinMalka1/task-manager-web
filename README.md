# Weekly Task Manager

A modern, full-stack weekly productivity web application designed for seamless task management with a clean interface tailored for Hebrew (RTL) users.

## Tech Stack
* **Frontend:** React, Vite, JavaScript, CSS3
* **Backend:** Python, FastAPI, RESTful APIs
* **Features:** 
  * Full-stack architecture with local data persistence.
  * Automated weekly date calculation dynamically updated based on the current week.
  * Complete RTL support with custom layout alignment.
  * Task creation, completion toggle, and full deletion capabilities.
  * Clean weekly reset mechanism.
